# The Speculator's Desk

*Commercial Real Estate, Global Macro, Market Intelligence, and the Art of Decision-Making Under Uncertainty*

A graduate-level self-study textbook and training laboratory for an experienced commercial real estate professional who wants to develop institutional speculative judgment: analyzing an unfamiliar asset, identifying what drives its value, understanding what is already priced, recognizing mispricing, quantifying risk, and making defensible buy, sell, hold, hedge, or wait decisions.

Commercial real estate, and hotels in particular, is the primary laboratory. Rates, credit, FX, equities, commodities, and derivatives are treated as parts of the same economic system.

## Quick start

```bash
cd speculators_desk
python3 -m pip install pytest openpyxl          # numpy/pandas not required by the core library
python3 -m pytest -q tests                      # verify every number (Excel tests need LibreOffice)
python3 scripts/desk.py list                    # list drills
python3 scripts/desk.py drill -n 5              # run five drills; progress saved locally
python3 scripts/desk.py drill --category A -n 10
python3 scripts/desk.py report                  # weekly performance report
python3 scripts/build_excel.py                  # regenerate the Excel workbook
python3 scripts/assemble.py --pdf               # manuscript + index + HTML + PDF
python3 scripts/progress.py                     # refresh PROGRESS.md metrics
python3 cases/hypothetical/case_A_overpriced_hotel_owner/case_a_model.py
```

Export dependencies: pandoc (HTML, using MathML so no network is needed) and Chromium or Chrome (PDF). In the build environment these were pandoc 3.1.3 and Chromium from Playwright. If either is missing, the Markdown manuscript is still produced.

## How to study
1. Take the baseline assessment (`training/weekly_exams/`), ungraded and diagnostic.
2. Follow `training/curriculum/16_week_program.md`. Each week has chapters, drills, a CRE exercise, a cross-asset exercise, two historical cases, and an exam.
3. Work every example by hand first (notebook and financial calculator), then in Excel, then check the Python. Chapter text names the test that reproduces each example.
4. Use the simulator daily. It grades calculations automatically and reasoning by rubric, and tracks errors by topic.
5. Keep the decision journal (`desk/trade_journal/`) from the first week.

## Simulator
`scripts/desk.py` runs drills from `training/daily_drills/drill_bank.json`. For each drill it presents the scenario, collects numeric answers and, for judgment drills, a decision (buy, sell, hold, hedge, wait, pass) with risk exposure and invalidation. It reveals the worked solution only after you submit. Calculations and reasoning are scored separately. Judgment drills use a transparent rubric that you self-score after reading the solution. The simulator does not declare one trade correct when the evidence supports several. Progress is stored in `training/performance_tracking/desk_progress.sqlite`, which is excluded from git. Simulated scores are not evidence of real-market trading ability.

## Conventions
See `textbook/frontmatter/03_notation_and_style_guide.md`. In brief: rates are decimals in code; monthly mortgage payments are in arrears at r/12; NOI is after reserves unless stated; FX pairs are BASE/QUOTE; long = +1, short = −1.
